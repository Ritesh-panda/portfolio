# Ritesh Ranjan Panda — Portfolio

> **AI/ML Engineer · Systems & Architecture · Research · Product & Program Thinking**  
> *"Research when the answer isn't known. Engineer when it is. Build when it matters."*

An Apple-grade personal developer portfolio and case study archive engineered with React, TypeScript, Tailwind CSS, Framer Motion, and Vite.

---

## ✨ Features & Architecture

- **Multi-Page Experience**:
  - **Home (`/`)**: Centered hero layout with 3D stylized avatar, 3D brand icons (GitHub, LinkedIn, Gmail), achievement badges, and adaptive navigation.
  - **Selected Work (`/work`)**: Two distinct sections:
    - *01 / Engineering Systems*: SocioOps (Residential Operations Platform with 153 automated assertions), JeevanRekha (Multilingual AI Assistant), and Low-Latency Semantic Search Engine.
    - *02 / Case Studies & Quantitative Analysis*: Cisco Forecast League 2026 (Rank #8 Finalist) and Bain BrAINWARS 2026 (PulseX Wearable Strategy).
  - **Achievements (`/achievements`)**: Dedicated multi-layer interactive case study modals for Amazon ML Summer School, Bain & Company, and Cisco Systems.
  - **Research (`/research`)**: Featured scientific publication breakdown and research domains.
  - **About (`/about`)**: Editorial segmented tab system covering profile background, education, experience, certifications, and leadership.
- **Micro-Interactions & Transitions**: Seamless page transitions with Framer Motion, responsive glassmorphism, and Apple-grade typography.
- **Full-Device Responsiveness**: Fluid layouts across 4K displays, standard laptops, tablets (iPad / Surface), and mobile viewports.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 8
- **Language**: TypeScript
- **Styling**: Tailwind CSS + Custom Design System
- **Animation**: Framer Motion
- **Icons**: Lucide React + Custom 3D SVG Icons
- **Routing**: React Router DOM v7

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Ritesh-panda/portfolio.git
cd portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
